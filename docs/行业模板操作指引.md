# 行业解决方案模板 · 操作指引

本指引说明「设置 → 行业模板」页面的用途与操作方法。该页面让你为本地运行的助手选择一个**垂直行业模板**，从而自动套用一套符合该行业合规要求的系统提示词、可用工具范围与安全策略。

> 适用版本：DoDidDoneUi（本地优先，数据不出本机）。

---

## 一、这是什么

行业模板是一组「预设规则」，用于约束助手在该行业场景下的行为：

| 维度 | 说明 |
| --- | --- |
| 系统提示词（System Prompt） | 定义助手的角色、语气与行业合规立场（如遵循《个人信息保护法》）。 |
| 可用工具 | 限定助手能调用的能力（文件读写、搜索、命令执行等）。 |
| 安全策略 | 决定哪些操作需要你手动审批，哪些被永久禁止。 |

套用模板后，助手在**每次新对话**中都会按该模板的规则运行，无需每次手动配置。

---

## 二、内置模板一览

| 模板 | 角色定位 | 默认约束要点 |
| --- | --- | --- |
| 法律合规助手 | 律所合规审查 | 只读分析，禁止修改/删除文件、禁止执行系统命令。 |
| 教学辅导助手 | 作业批改与知识点讲解 | 可读写作业文件，禁止执行系统命令。 |
| 医疗数据助手 | 敏感健康信息处理 | 数据严禁出本机；只读分析，禁止上传网络、禁止执行命令、禁止改文件。 |
| 金融风控助手 | 交易与审计数据分析 | 可运行只读审计命令，严禁修改/删除文件或执行危险命令。 |

> 各模板的「已禁用工具」与「审批策略」会直接显示在卡片上，供你确认。

---

## 三、如何操作

1. 打开 **设置 → 行业模板**。
2. 在模板卡片中选择一个（卡片高亮即表示已选中）。
3. （可选）在 **公司覆盖（JSON）** 中填写额外约束，进一步收紧规则（见下一节）。
4. 点击 **保存**。
5. 若要恢复为「不使用模板」，点击 **清除选择** 即可。

保存后，新发起的对话即生效；已在进行的对话不受影响。

---

## 四、公司覆盖（Company Override）怎么填

这是一段**可选**的 JSON，会「合并」到你所选模板的基线配置之上，用于在你的公司/团队场景下**进一步收紧**约束。

### 支持的字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `excluded_tools` | string[] | 在模板基础上**额外禁用**的工具列表。 |
| `approval_policy` | `"always"` \| `"dangerous"` | `always` = 所有工具调用都需你审批；`dangerous` = 仅危险操作需审批（模板默认）。 |

### 示例

只禁用命令执行、并要求所有操作都审批：

```json
{
  "excluded_tools": ["shell_exec"],
  "approval_policy": "always"
}
```

不填（留空 `{}`）即直接使用模板默认配置，完全没问题。

### ⚠️ 重要红线：只能更严，不能更松

无论你怎么写，**模板锁定的安全底线都无法被放宽或关闭**，例如：

- 禁止删除/破坏系统或用户文件；
- 禁止将敏感数据（医疗、金融、个人身份信息）传出本机；
- 禁止绕过审批直接执行高危命令。

`excluded_tools` 只能往里加、不能把模板已禁用的工具「放出来」；`approval_policy` 只能从「仅危险」升级到「全部」，不能降级到「全免审」。填写非法 JSON 会在保存时提示错误。

## 五、常见问题

**Q：选了模板还要配置模型吗？**
A：要。模板只管「规则」，对话所需的模型（如 DeepSeek 等国产大模型 API Key）仍需在「模型」设置中配置。

**Q：模板会影响已有对话吗？**
A：不会。模板仅作用于保存后新发起的对话。

**Q：能否为自己定制的助手单独套模板？**
A：当前模板是**账号级**的全局设置，对所有新对话统一生效。
